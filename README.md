\# Вариативная часть. Задание 5: тестирование программных модулей

&#x20;

Проект ShoeStore.Logic содержит класс ProductCalculator (Приложение 4), проект ShoeStore.Tests - модульные тесты MSTest.

&#x20;

\## Протокол тестирования

&#x20;

Фреймворк модульного тестирования: MSTest (.NET 8).

&#x20;

Порядок запуска тестов:

1\. Открыть решение в Visual Studio 2022.

2\. Меню «Тест» -> «Обозреватель тестов».

3\. Нажать «Запустить все тесты в представлении».

&#x20;

Запуск из командной строки (в папке решения): dotnet test
